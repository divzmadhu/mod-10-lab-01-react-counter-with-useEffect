# Lab 10.1 React Counter with useEffect 

## Overview

This is an Advanced Counter application built using React, TypeScript, and CSS. It allows users to increase and decrease the count, choose a custom step value, and view the count history.

## Features

* Increment and decrement the counter using buttons.
* Set a custom step value.
* View the history of count changes.
* Reset the counter and clear the history.
* Save the count in localStorage and restore it when the page is refreshed.
* Use Arrow Up and Arrow Down keys to change the count.

## What I Learned

* Using `useState` to manage multiple state values.
* Using `useEffect` to handle side effects.
* Saving and retrieving data using localStorage.
* Adding keyboard event listeners.
* Cleaning up event listeners using the `useEffect` cleanup function.
